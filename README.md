# 🚀 PostEase AI - ระบบโพสต์เพจอัตโนมัติ (เพจรถสไลด์ & อาหารหมู)

ระบบช่วยคิดแคปชันด้วย AI (Gemini Vision) พร้อมระบบตั้งเวลา คิวโพสต์อัตโนมัติ และเชื่อมต่อแชทบอท LINE

---

## 💻 วิธีเปิดใช้งานโปรแกรม (ง่ายที่สุด)

เพียง **ดับเบิลคลิกไฟล์ `run.bat`** บนหน้า Desktop:
1. ระบบจะติดตั้งไลบรารีที่จำเป็นให้โดยอัตโนมัติ
2. เบราว์เซอร์จะเปิดหน้าเว็บขึ้นมาที่ **`http://localhost:8000`** ทันที พร้อมใช้งาน!

---

## 🌟 ฟังก์ชันหลักของระบบ

1. **Dashboard หน้าหลัก (`/`):**
   * มีปุ่มสลับเพจด้านบนขวา (`🚗 เพจรถสไลด์` / `🐷 เพจอาหารหมู`)
   * อัปโหลดรูปภาพจริงหน้างาน
   * AI สแกนภาพและสร้างแคปชันให้เลือก 3 สไตล์:
     * ⚡ **แบบด่วน:** เน้นเบอร์โทรฉุกเฉิน ติดต่อไว
     * 📖 **แบบเล่าเรื่องหน้างาน:** เล่าบรรยากาศการบริการ สร้างความเชื่อมั่น
     * 🏷️ **แบบโปรโมชัน:** เน้นราคาพิเศษ แจ้งรอบส่ง
   * แก้ไขข้อความในกล่องได้อย่างอิสระ
   * กล่อง **Auto First Comment** ปักหมุดเบอร์โทรและไลน์ติดต่ออัตโนมัติ
   * เลือกว่าจะ **"⚡ โพสต์ทันที"** หรือ **"📅 ตั้งเวลาล่วงหน้า"**

2. **หน้ารวมคิวโพสต์ (`/queue`):**
   * ตรวจสอบโพสต์ที่รอปล่อยคิวทั้งหมด พร้อมตัวกรอง (ทั้งหมด / รอโพสต์ / โพสต์แล้ว)
   * ปุ่มจัดการด่วน: `✏️ แก้ไข`, `⚡ โพสต์ทันที`, `🗑️ ลบคิว`

3. **หน้าตั้งค่า (`/settings`):**
   * ใส่ Facebook Page ID และ Page Access Token ของทั้ง 2 เพจ
   * ใส่เบอร์โทรติดต่อ และไอดี LINE สำหรับปักหมุดในคอมเมนต์
   * ใส่ Google Gemini API Key และ LINE Messaging Token

4. **ระบบ LINE Bot (`/api/line/webhook`):**
   * ผู้ใช้ส่งรูปหน้างานผ่านแชท LINE
   * บอทตอบกลับเป็นการ์ด 3 สไตล์ ให้ผู้ใช้กดเลือกใน 1 คลิก
   * บอทช่วยยิงโพสต์ขึ้นเพจ หรือตั้งเวลาโพสต์ให้อัตโนมัติ

---

## 🔒 ความปลอดภัย
* ระบบนี้ **ไม่ใช้รหัสผ่าน Facebook** ใช้เพียง Page Access Token ที่มีสิทธิ์แค่โพสต์รูปและคอมเมนต์เท่านั้น
* ข้อมูลทั้งหมดถูกจัดเก็บไว้ในฐานข้อมูล `poster.db` (SQLite) ภายในเครื่องของคุณเอง ปลอดภัย 100%
