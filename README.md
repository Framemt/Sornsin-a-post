# 🖼️ ศรศิลป์ กรอบรูป - AI Studio & Facebook Auto-Poster

ระบบบริหารจัดการคิวโพสต์เพจ Facebook อัตโนมัติสำหรับร้าน **ศรศิลป์ กรอบรูป** ขับเคลื่อนด้วยสมองกล AI (Gemini Vision) พร้อมระบบปักลายน้ำโลโก้ร้านอัตโนมัติ เชื่อมต่อแชทบอท LINE และระบบความปลอดภัยเต็มรูปแบบ

---

## 🌟 ฟังก์ชันหลักของระบบ (Features)

### 1. 🎨 สตูดิโอสร้างโพสต์อัจฉริยะ (AI Post Studio - `/`)
- **รองรับอัลบั้มหลายรูปภาพ (Multi-Image / Album):** อัปโหลดภาพงานกรอบรูปพร้อมกันได้ทั้งรูปเดี่ยวและอัลบั้ม (JPG, PNG, WEBP)
- **💧 ระบบลายน้ำอัจฉริยะ (Smart Watermark):**
  - ประทับตราโลโก้ร้านแบบมุมมนโปร่งแสง ไม่บดบังรายละเอียดงานศิลปะ
  - โหมด **🤖 AI Auto** วิเคราะห์หาตำแหน่งมุมว่างของภาพให้อัตโนมัติ
  - หรือเลือกตำแหน่งได้เอง: บนซ้าย, บนขวา, ล่างซ้าย, ล่างขวา
- **🎯 คัดกรองตามหมวดหมู่งานกรอบรูป:**
  - 🖼️ งานสั่งทำทั่วไป
  - 🌟 กรอบรูปมงคล
  - 🎓 ของขวัญ / รับปริญญา
  - 💍 แต่งงาน / พรีเวดดิ้ง
  - 🪞 กระจกเงาแต่งบ้าน
- **🧠 AI คิดแคปชันอัตโนมัติ 3 สไตล์ (Gemini Vision):**
  1. ⚡ **ใส่ใจรายละเอียด:** เน้นงานฝีมือ ประณีต เข้ามุมสวยงาม
  2. ✨ **คุณค่าและความทรงจำ:** เน้นความหมาย อารมณ์ และคุณค่าทางใจ
  3. 🎨 **สั่งทำตามใจลูกค้า:** เน้นการบริการ โทนสีและขนาดตามสั่ง ให้คำแนะนำฟรี
- **📱 จำลองโพสต์ Facebook เสมือนจริง (Live FB Simulator):** เห็นตัวอย่างการแสดงผลจริงทั้งข้อความและรูปภาพก่อนกดยืนยันโพสต์
- **📌 Auto First Comment:** ระบบปักหมุดคอมเมนต์แรกอัตโนมัติ (เบอร์โทร, พิกัดร้าน, LINE OA)
- **⏰ ระบบตั้งเวลา & ปล่อยคิวทันที:**
  - ⚡ **โพสต์ทันที:** ส่งขึ้นหน้าเพจ Facebook พร้อมคอมเมนต์ปักหมุดในคลิกเดียว
  - 📅 **ตั้งเวลาล่วงหน้า:** เลือกเวลาสะดวกด้วยปุ่มลัดด่วน (อีก 30 นาที, อีก 1 ชม., เย็นนี้ 18:00, พรุ่งนี้ 18:00)
  - ⚡ **กระจายคิววันละ 1 โพสต์:** ฟังก์ชันจัดตารางปล่อยคิวโพสต์ตอน 18:00 น. วันละ 1 โพสต์อัตโนมัติ

---

### 2. 📋 หน้ารวมและจัดการคิวโพสต์ (`/queue`)
- ดูสถานะคิวทั้งหมด แยกหมวดหมู่: **รอโพสต์ (Scheduled)** / **โพสต์แล้ว (Published)** / **ล้มเหลว (Failed)**
- จัดการคิวได้ทันที:
  - ✏️ **แก้ไขข้อความ / เลื่อนเวลา**
  - ⚡ **กดปล่อยคิวโพสต์ทันที**
  - 🗑️ **ลบคิวที่ไม่ต้องการ**
- มีปุ่ม **"⚡ กระจายคิวทุกโพสต์ (18:00 น.)"** ช่วยจัดระเบียบเวลาคิวที่ค้างอยู่ให้อัตโนมัติ

---

### 3. ⚙️ หน้าตั้งค่าระบบครบวงจร (`/settings`)
1. **ข้อมูลเพจร้าน:** จัดการ Facebook Page ID, Page Access Token, เบอร์โทร, LINE ID, พิกัด Google Maps
2. **ระบบลายน้ำ (Smart Watermark):** เปิด/ปิดลายน้ำ, กำหนดตำแหน่งเริ่มต้น, ปรับระดับความโปร่งแสง (Opacity)
3. **Facebook App Token Exchange:** แลกเปลี่ยน Token ระยะสั้นให้กลายเป็น Token ถาวร (Long-lived Token) อัตโนมัติ
4. **กุญแจ API สมองกล:** บันทึก Google Gemini API Key และ LINE Messaging API Token / Secret
5. **ความปลอดภัยบัญชีแอดมิน:** เปลี่ยน Username และ Password ผู้ดูแลระบบ
6. **🩺 ตรวจสุขภาพระบบ (Health Diagnostics):** ตรวจเช็คสถานะการเชื่อมต่อสดของ Facebook, Gemini, LINE และ Cloudflare Tunnel
7. **💾 สำรองฐานข้อมูล (1-Click Backup):** ดาวน์โหลดไฟล์ฐานข้อมูล `poster.db` เก็บสำรองได้ในคลิกเดียว

---

### 4. 💬 ระบบรับงานผ่าน LINE Bot (`/api/line/webhook`)
- ช่างหรือแอดมินส่งรูปหน้างานผ่าน LINE ได้โดยตรง
- บอทตอบกลับเป็นการ์ดสรุปแคปชัน 3 สไตล์ ให้กดเลือกโพสต์หรือตั้งเวลาได้จากในแชท
- เมื่อโพสต์สำเร็จ บอทจะส่งลิงก์ Facebook Post กลับมาให้ทันที
- สคริปต์ `auto_tunnel.py` ช่วยอัปเดต Webhook URL เข้า LINE Developers ให้อัตโนมัติ

---

### 5. 🛡️ ความปลอดภัยและการรักษาความปลอดภัย (Security)
- **ระบบ Login & JWT Session:** ตรวจสอบสิทธิ์ผู้ใช้งานอย่างรัดกุม
- **Idle Auto-Logout:** หากไม่มีการใช้งานหน้าจอเกิน 1 ชั่วโมง ระบบจะตัด Session และดีดกลับไปหน้า Login ทันที
- **Local Data Storage:** จัดเก็บข้อมูลและรูปภาพในฐานข้อมูล SQLite ภายในเครื่อง ไม่รั่วไหลไปคลาวด์ภายนอก

## 💻 วิธีเปิดใช้งานโปรแกรม

### วิธีที่ 1: ดับเบิลคลิกไฟล์สคริปต์ (ง่ายที่สุด)
1. ดับเบิลคลิกไฟล์ **`run.bat`**
2. ระบบจะตรวจสอบสภาพแวดล้อม Python, เริ่มการทำงานของ Server และเปิดหน้าเว็บเบราว์เซอร์ให้ที่:
   ```text
   http://localhost:8000/login
   ```
3. หากต้องการปิดโปรแกรม สามารถดับเบิลคลิกไฟล์ **`stop.bat`** ได้ทันที

---

### วิธีที่ 2: รันผ่าน Command Line / Terminal
```bash
# 1. เข้าสู่โฟลเดอร์โปรเจกต์
cd C:\Users\Leno2\Desktop\fb-auto-poster

# 2. เรียกใช้งาน Virtual Environment
.\venv\Scripts\activate

# 3. รันเซิร์ฟเวอร์ Uvicorn
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
